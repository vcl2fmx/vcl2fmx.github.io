Language packs and mapping packs do different jobs.

The 35 language packs control the converter's displayed language. The bundled JSON mapping packs describe VCL-to-FMX conversion rules. Both are included in the complete V7 packages.

For adding languages or editing translations and glossaries, use the Delphi App Translation Studio and download its manuals and guides with the software.

For conversion-rule editing, the existing JSON Mapping Pack Studio is a separate tool. Changing a translation does not create a new component conversion rule.
