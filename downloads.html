After downloading

A safe first conversion

  1. Extract the complete source distribution.
  2. Open VCL2FMXConverter.dproj in RAD Studio.
  3. Build and run the converter on Windows.
  4. Choose a backed-up VCL project and a separate output folder.
  5. Open the generated FMX project, read the HTML report, compile, and test.

Build requirements

Delphi development environment

The source repository is intended for Windows with Embarcadero Delphi/RAD Studio and FireMonkey support. Version 6.0 supports Delphi 12 or later and is currently built with Delphi 13.1. Very old projects, including Delphi 3-era code, may need manual modernization before conversion.
