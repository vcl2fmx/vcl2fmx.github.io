# VCL2FMXConverter v6.0 Navigator Project Directives

## Backup destination

- Effective August 4, 2026, all project backups must be written to the `G:\` drive.
- The `G:\` drive replaces the previously used `D:\` backup drive. Do not use `D:\` for future backups.
- Project backup folders must continue to identify the applicable project clearly.

## Documentation identity

- Current user-facing documentation must identify the product as `VCL2FMXConverter v6.0 Navigator`.
- Current DOCX guides, companion PDFs, Help content, README material, document titles, headers, footers, and ordinary documentation prose must not advertise or depend on a per-iteration build number.
- Build numbers remain appropriate in the application UI, executable version metadata, public web pages, release notes, validation results, audit records, archived build history, and source-distribution records.
- Documentation filenames should remain stable at the v6.0 Navigator level. A compatibility copy may retain an older filename only when an unchanged external or web link still depends on it; the document content itself must remain build-neutral.
- When documentation is regenerated, preserve the established Word formatting and create companion PDFs through Microsoft Word. Do not use LibreOffice.
